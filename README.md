
# 💗 MAS Submod - Virtual Love
A submod that adds more romance in your [Monika After Story](https://github.com/monika-after-story/monikamoddev)! Including new compliments, interactions, LGBTQ+ elements, and much more!

## 🌸 Features
- 8 New songs!
- 3 Added compliments!
- 9 Added interactions!
- 7 More topics!
- Aroace/QPR options!

## 🍄 Installation
[Download the newest release here](https://github.com/betapop/Beta-MAS-vl/releases) and extract the zip. Take the `game` folder and drag it into your DDLC folder. This folder could be named something like `DDLC-1.1.1-pc`! Place the `game` folder inside this folder and let it write into/override the content.

Alternatively, you can take the `Virtual Love` folder from inside the `Submods` folder and put it into your submod folder. Whichever works better for you!

If you had version 1.0 or 1.1 of this mod, you will likely see topics you've already read unmarked again. Sorry for the inconvenience! In better news, some topics have been rewritten— so look out for that while playing.
